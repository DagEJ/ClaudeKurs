# ClaudeKurs – minispill

En samling små enmannsspill i ren HTML, CSS og JavaScript, laget under et kurs i agentisk utvikling med Claude.

## Kom i gang

Åpne `index.html` i nettleseren. Ingen installasjon eller bygging trengs.

Kjør testene for spill-logikken (krever Node 18+):

```
node --test
```

## Nytt spill

Kopier `games/_mal/` til `games/<navn>/`, bygg spillet og legg det til i `games/registry.js`.
Se [CLAUDE.md](CLAUDE.md) for struktur og konvensjoner.
